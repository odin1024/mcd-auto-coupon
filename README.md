## 这是什么？

麦门券官是一款**以"你手里的券"为中心的券资产智能管家**：打开页面，点一下「一键领取」自动领光麦麦省全部可领优惠券，然后你会得到一张**把券、积分、活动全部换算成钱的驾驶舱**——券面值合计、即将到期的沉默成本、本月清零积分，一眼看清。

V2.0 新增三大能力，从"管券"升级到"用券"：

- **💰 券资产驾驶舱**：把券包换算成钱——券面值合计 ¥X、可用积分、即将过期 = 沉默成本（红色预警）、立减券预计可省，全部诚实口径、不虚报；
- **✨ 智能用券决策**：每张券旁边都有「怎么用最值」——你手里的券 → 匹配菜单 → 调官方 `calculate-price` 真实计价 → 给出 TOP 3 最划算方案（原价 → 券后价、省多少、折扣率），甚至能算到"白拿"；
- **📊 一键生成省钱战报**：Canvas 绘制的竖版分享长图——券资产大数字 + 券包清单 + 今日活动 + 开源引流，一键保存 PNG，发朋友圈/小红书直接涨 Star。

一句话：**别人的券在钱包里吃灰，你的券被麦门券官算得明明白白——连怎么花最值都替你算好了。**

## 快速开始

### 环境要求

- Node.js **18 或更高版本**（内置 `fetch`，零第三方依赖，无需 `npm install`）

### 1. 克隆并启动（演示模式）

```bash
git clone https://github.com/odin1024/mcd-auto-coupon.git
cd mcd-auto-coupon
node server.js
```

打开浏览器访问 `http://localhost:3001`，点击「一键领取全部优惠券」即可完整体验领券全流程（此时使用内置模拟数据，界面会显示"演示模式"徽标）。

### 2. 接入真实麦当劳 MCP

从 [麦当劳 MCP 官方平台](https://open.mcd.cn/mcp) 登录并激活申请 MCP Token（此 Token 代表您的麦当劳会员身份，请严格保管）。

```bash
export MCD_MCP_TOKEN=你的Token
node server.js
```

服务启动日志会显示 `REAL（真实麦当劳 MCP）` 模式。此时券列表、领券、积分、活动、菜单与官方计价均来自麦当劳官方实时接口。

> 安全提醒：请通过环境变量传入 Token，**切勿**把 Token 写入代码、配置示例或提交到仓库。

## 真实使用麦当劳 MCP

| MCP 工具 | 用途 | 在本项目中的作用 |
|---|---|---|
| `available-coupons` | 查询麦麦省可领优惠券列表 | 领券前扫描"可领 / 已领 / 不可领"状态 |
| `auto-bind-coupons` | 一键领取全部可领优惠券 | 核心写操作，领取后返回 couponId/couponCode |
| `query-my-coupons` | 查询我的优惠券 | 领券前后两次核对，展示券资产看板 |
| `query-my-account` | 查询我的积分账户 | 积分概览（可用/累计/冻结/到期） |
| `campaign-calendar` | 查询当月活动日历 | 今日活动雷达 |
| `query-meals` | 查询门店菜单 | 用券决策的餐品池（V2.0） |
| `calculate-price` | 官方真实计价 | 用券决策的核心计价（V2.0，单位"分"自动转元） |

完整的接入地址、协议、调用流程与安全边界见 [MCP_INTEGRATION.md](./MCP_INTEGRATION.md)。

## 安全边界

- 不在仓库、配置示例、命令脚本中保存任何真实 Token、手机号、地址等个人信息；
- 未配置 Token 时自动进入演示模式，不会发起任何外网请求；
- 本项目仅使用麦当劳 MCP 的**领券/查券类能力**，不涉及下单、支付；
- 券价值与沉默成本只统计**能明确量化的金额**（立减/用券价面值），半价、折扣等无法量化的券**不虚报**；
- 用券决策的计价结果全部来自官方 `calculate-price`，Mock 模式明确标注"演示数据"；
- 优惠券、价格、活动以麦当劳官方渠道的实时结果为准。
